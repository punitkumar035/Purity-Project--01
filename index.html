Use Universal Flow / Stream for syrup, juice, sweet water, clear juice, wash water, condensate, hot water, steam and vapour. The connector's topology determines whether it is an external input, internal flow, or product/output.
Universal Stream rule:
The connector itself is the flow object and the boundary stencil.

Input port → blank canvas = External Input.
Output port → input port = Internal Flow.
Output port → blank canvas = Product / External Output.

Drag Universal Flow / Stream onto blank canvas when you want a free Visio-style stream stencil before connecting it.

Topology rule: one process stream per equipment output port. Use a Splitter for branching.
