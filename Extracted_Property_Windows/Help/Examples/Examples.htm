About Examples

 

Twelve flow diagram example models are provided with Sugars. Each example is identified by its ".vsd" and ".sgd" files. The names for each of the examples are:

 

NAME

DESCRIPTION

Single Crystallization

Simple model of a pan, crystallizer and centrifugal with instructions on how to build the model.

4-Effect multiple

Four-effect multiple-effect evaporator station with flashing between effects.

6-Effect Multiple

Six-effect multiple-effect evaporation with juice heating, thermocompressor, split condensate flashing, and standard liquor concentration.

Beet Sugar End

Beet factory sugar end with multiple-effect evaporation.

Beet Factory

Beet sugar factory having diffusion, pulp pressing, carbonation/purification, evaporation, sugar boiling, and sugar drying.

Cane Factory (Milling)

Cane sugar factory having milling, clarification, evaporation and crystallization with steam for the process provided by a bagasse boiler.

Cane Factory (Diffusion)

Cane sugar factory with diffusion, clarification, evaporation and crystallization.

Fermentation and Distillation

Fermentation of molasses and distillation with stripping and rectifying columns to produce hydrous ethanol.

Ion Exchange

Ion exchange for decolorizing juice.

Molasses Desugarization

Molasses desugarization system with molasses receiving, filtering, chromatographic separation and extract concentration.

Refinery

Cane sugar refinery with affination, phosphatation purification, liquor decolorization, countercurrent liquor evaporation, four white strikes, three remelt boilings, sweet water multiple-effect evaporation, and sugar drying.

Steam Pulp Dryer

Example of high-pressure steam pulp dryer with diffusion, pulp pressing, pressure reducer/desuperheater, turbo generator, and thin juice evaporation.

 

 

Complete input data is provided for all of the examples except the Single Crystallization model. Only the flow diagram is given for this example so that the procedure for creating a flow diagram and entering all of the required data can be illustrated (see Single Crystallization). Input data for each of the other eleven examples can be reviewed and/or modified by simply selecting the desired model from the "C:\Program Files\Sugars\Examples" directory. Models are selected by either double clicking on the ".vsd" file from Windows Explorer, or using the Open command to open the ".vsd" file from within Visio. Different modeling techniques are illustrated in each example. All example data files are shown in SI units, but they can be easily changed to US units from within Sugars.
