File Structure

 

Data for each model is stored in a Microsoft Access database.  The database file for a model has a ".sgd" extension; whereas, the Visio drawing file has a ".vsd" extension.  Each station type has a table in the database where all of the station data for each of the stations of that type are stored.  For example, data for each centrifugal in a model is stored in the "tblCentrifugal" table of the Access database for the model.  Each row in the table for a station type contains the data for one station in the model of the same station type.  Each column in the table contains data for one of the properties of the station.  All columns for each table are labeled as to their corresponding property on the station property window.

 

All flow streams are stored in a separate table called "tblFlows".  Each row contains the data for each flow stream in a model and the columns contain the data fields for each flow stream.  External flow streams (flows into the model from outside sources) have a "0" in the field for the "StationFromNumber" column.  Internal flow streams (flows going between stations) that leave the model have a "0" in the field for the "StationToNumber" column.  All columns are labeled to give the properties of the flow stream to correspond with the characteristics of the flow.  For example, pressure, temperature, quantity, components, solubility coefficients, and color.
